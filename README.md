# ⚡ TECH CLASH ARENA — COMPLETE USER GUIDE

Tech Clash Arena is a real-time interactive multiplayer tech tournament web application built for classroom smartboards and student mobile devices.

---

## 🚀 Quick Start in 10 Seconds

1. Go to folder **`D:\WEGROW\14.Game`**.
2. Double-click **`START_GAME.bat`**.
   - A server console will open and display:
   - `🖥️ Smartboard Screen: http://localhost:3000/smartboard.html`
   - `📱 Students Mobile:  http://192.168.29.60:3000/player.html`

---

## 🖥️ Smartboard Controls:
1. Open Chrome on the Smartboard and visit **`http://localhost:3000/smartboard.html`** (Press **F11** for Fullscreen).
2. A large QR Code and URL will be displayed on screen.
3. Students scan the QR code with their mobile phone cameras, enter their name, and choose their track (Full Stack / Data Analyst / Data Scientist).
4. No matter how many students join (5, 7, 10, or 15+):
   - Tap **`🔀 Smart Auto-Balance Teams`** on the Smartboard.
   - The engine automatically distributes players into balanced teams (Alpha, Beta, Gamma, Delta).
5. Tap **`START TOURNAMENT ▶`** to begin!

---

## 🎮 During Gameplay:
* **Auto 3-Sec Buzzer:** When each question appears, a 3-second countdown (3... 2... 1...) runs, then buzzers unlock automatically on all student phones!
* **First-to-Buzz Answering:** The fastest team gets control. The answer options appear directly on their mobile phone!
* **Instant Audio-Visual Feedback:**
  - 🟢 **Correct Answer:** Screen flashes green, plays a chime, launches confetti, and awards +100 points.
  - 🔴 **Wrong Answer:** Screen shakes and flashes red, deducts -20 points, locks that team, and passes the turn to the 2nd team in the queue!
* **Smartboard Touch Controls:**
  - 🟢 **[ ✅ CORRECT (+100) ]** — Manually mark an answer as correct.
  - 🔴 **[ ❌ WRONG / PASS ]** — Mark as wrong and pass to the next team in line.
  - 💡 **[ 💡 REVEAL ANSWER ]** — Shows the correct answer and a simple explanation on the smartboard.
  - ➡️ **[ NEXT QUESTION ▶ ]** — Moves to the next question.

---

## 📚 7 Game Rounds (200 Questions Total):
1. **Round 1: The Bidding MCQ** (30 Questions) — Point bidding with real-world tech questions.
2. **Round 2: Tech Connections** (30 Puzzles) — Visual emoji connection puzzles.
3. **Round 3: Odd One Out (The Imposter)** (30 Questions) — Find the imposter technology among four options.
4. **Round 4: Tech Detective (Who Am I?)** (30 Puzzles) — 3 progressive clues revealing a mystery tech concept.
5. **Round 5: Future or Fired? (4-Team Debate)** (30 Topics) — Structured 4-way tech debate topics.
6. **Round 6: The Tech Millionaire** (30 Questions) — KBC-style 4-choice questions with lifelines.
7. **Round 7: Rapid Fire Clash** (20 Questions) — High-speed 30-second rapid fire questions with options.

🏆 At the end, tap **`👑 Declare Winner`** to display the grand champion podium with confetti celebration!
